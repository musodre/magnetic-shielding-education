# Prepared package 1.0.0

- Shared exact fields and shielding factors with interface and limit checks.
- Exact geometry reversal at k=(1+sqrt(33))/16.
- Quantitative B magnitude maps with explicit field-line interpretation.
- Runnable proposed activities, reference CSV/JSON results and approximation thresholds.
- Modal finite-volume verification with separate mesh and far-boundary errors.
- MIT license and software citation metadata.

This package is prepared locally for a separate `magnetic-shielding-education` repository. The original repository identified in the manuscript, https://github.com/xedwfe/magneticshielding, is retained as the provenance reference and is not modified.
